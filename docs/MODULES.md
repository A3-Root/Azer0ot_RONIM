# RONIM - Modules

## Zeus (needs ZEN), category *RONIM*

| Module | Placement | Effect |
|---|---|---|
| RONIM Settings | anywhere | Pick a settings group, then edit the values as mission overrides. A checkbox at the end clears that group's overrides instead. |
| Toggle Features | anywhere | Set each feature to Keep (CBA), Off or On. |
| Toggle Exempt | on a unit | Toggles whether the unit is exempt from RONIM. |
| Break NVG Mount | on a unit | The unit's NVGs fall to the ground. |
| Re-seat NVG Mount | on a unit | Clears the unit's mount misalignment. |
| Integrated NV Optics | anywhere or on a unit | Add or remove optic classes treated as integrated NV. When placed on a unit, it can add that unit's current optic. |

## 3DEN, category *RONIM*

| Module / attribute | Effect |
|---|---|
| RONIM Settings (module) | Has one attribute per CBA setting. *Keep setting* (-1, or empty text) leaves a setting alone; any other value overrides it for the mission. |
| RONIM Exempt Units (module) | Exempts synced units and the rest of their groups, or lifts the exemption when *Exempt* is off. |
| RONIM: exempt (unit attribute) | Found under Attributes > RONIM. Exempts that unit. |
